# چک‌لیست لانچ اول کیمیا

آخرین بررسی: ۲۰ آبان ۱۴۰۵ (2026-11-11).

محدوده: معرفی سالن و خدمات، نمونه‌کار، تماس مستقیم و پنل مدیریت محتوا.
تیک‌ها فقط به معنی تأیید در سطح نوشته‌شده هستند؛ تست محلی معادل تأیید تولید نیست.

- [x] اصلاح دامنه canonical و اطلاعات ساختاریافته صفحه اصلی و صفحات خدمات؛ بررسی با پاسخ آزمایشی دیتابیس.
- [x] درج خدمات دریافتی در sitemap؛ بررسی با پاسخ آزمایشی دیتابیس.
- [x] پاسخ 404 صفحه خدمت غیرفعال؛ بررسی با پاسخ آزمایشی دیتابیس.
- [x] حذف لینک نوبت مخفی از ناوبری مشترک صفحات فرعی.
- [x] اصلاح مستندات راه‌اندازی برای معرفی خدمات و غیرفعال ماندن SMS و عضویت مشتری.

- [x] اعمال متن معرفی اصلی، نام نمایشی سالن و تمام نشانی‌های نمایشی از تنظیمات.
- [x] تبدیل لینک‌های باقی‌مانده #booking در صفحه اصلی و آتلیه به تماس قابل تنظیم.

## محدودیت این بررسی

اتصال واقعی تولید، ورود مدیر، آپلود واقعی و انتشار عمومی تأیید نشده‌اند. بررسی مرورگری محلی انجام شد؛ پاسخ‌های پنل در فایل محلی به‌دلیل نبود احراز هویت/اتصال واقعی قابل استفاده نبودند.
در این بررسی migration تولید، SMS واقعی، تغییر secret، انتشار، commit یا push انجام نشد.
بازبینی مجدد: build، test و lint پاس شدند. fillSettings با وضعیت‌های true و false در مرورگر اجرا شد و formData نیز حفظ همان وضعیت را تأیید کرد.
