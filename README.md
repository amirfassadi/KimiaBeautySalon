# سالن زیبایی کیمیا | KimiaBeautySalon

این ریپو محل اصلی کد سایت، پنل مدیریت، بک‌اند و مستندات کیمیاست.

**ریپوی اصلی:** https://github.com/amirfassadi/KimiaBeautySalon  
**سایت فعلی:** https://kimia-beauty-salon.miranco-projects.chatgpt.site

## شروع در VS Code

Node.js LTS پشتیبانی‌شده (حداقل 22) و npm نصب باشد:

```bash
npm ci
npm run dev
```

پیش‌نمایش روی http://localhost:3000 است. نیازی به نصب Bash نیست.

```bash
npm run build
npm test
npx tsc --noEmit
```

`npm run build` خروجی Worker سازگار با Sites را در `dist/server/index.js` می‌سازد؛ مسیر مستقل Node نیز همین برنامه را با PostgreSQL و ذخیره‌سازی محلی تصویر اجرا می‌کند. `npm run start` فقط برای استقرار مستقل با تنظیمات سرور است؛ `npm run preview` ابزار توسعه است و production نیست. خروجی `dist/` را به Git اضافه نکنید.

## وضعیت قابلیت‌ها

- در لانچ معرفی، بازدیدکننده خدمات، نمونه‌کار و راه‌های تماس را می‌بیند؛ عضویت مشتری، SMS، پرداخت و نوبت‌دهی آنلاین عمومی فعال نیستند. کد و جدول‌های آینده حذف نشده‌اند.
- درخواست زمان پیشنهادی، نوبت قطعی نیست؛ تأیید نهایی توسط سالن انجام می‌شود.
- پیش‌نمایش محلی عمداً دیتابیس و هویت مدیر میزبانی‌شده را فعال نمی‌کند؛ ذخیره اطلاعات مشتری یا ورود جعلی وجود ندارد.
- احراز هویت مشتری فعلاً کاملاً غیرفعال است و UI فقط پیام «به‌زودی» نمایش می‌دهد. Endpointها و migration آزمایشی در کد باقی مانده‌اند، اما migration 004 و OTP/SMS/session در production فعال نیستند.
- دیتابیس موردنیاز PostgreSQL است. استقرار موجود Sites از Supabase/PostgREST استفاده می‌کند؛ برای VPS مسیر مستقل Node، اتصال مستقیم pool و ذخیره‌سازی محلی تصویر در `server/` آماده شده است.
- فعال‌بودن تولید به اجرای migrationها و تنظیم محرمانه اتصال وابسته است؛ وجود کد، تأیید اتصال واقعی نیست.
- قیمت خدمات، پرداخت آنلاین، ارسال پیامک و رابط کامل انگلیسی در این پیاده‌سازی فعال نیستند.
- تصاویر موجود مفهومی‌اند و با تصاویر واقعیِ دارای مجوز جایگزین می‌شوند.

## PostgreSQL و تولید

برای مسیر قدیمی Sites، راهنمای همین صفحه در `docs/OPERATIONS.md` و migrationهای 001 تا 003 معتبرند. برای VPS، از `docs/SELF_HOSTING.md` استفاده کنید: runner مستقل ترتیب 001 تا 003 و سپس 005 را مدیریت می‌کند؛ migration 004 عمداً اجرا نمی‌شود. مقادیر `.env.example` نمونه‌اند؛ اسرار را به Git اضافه نکنید.

ورود مدیر در مسیر Sites به هویت تأییدشده Sites وابسته است؛ مسیر مستقل VPS ورود جداگانه با session سمت سرور و ابزار امن ساخت مدیر دارد. کد و مستندات VPS به معنی اتصال یا تأیید محیط واقعی نیستند.

سایت فعلی و دسترسی آن در این یکپارچه‌سازی تغییر نکرده‌اند. Sites برای انتشار، مخزن داخلی مدیریت‌شده خود را نگه می‌دارد؛ مرجع توسعه دستی فقط این ریپوی GitHub است.

## معماری و آرشیو

طرح SmartCore از ریپوی قدیمی حفظ شده است. کد فعلی یک پیاده‌سازی مستقل سالن است و نباید ادعا شود اکنون به SmartCore متصل است. مستندات آرشیو نقشه راه و سابقه تصمیم‌ها هستند؛ دستور اجرای فعلی یا الزام ساخت هم‌زمان ماژول‌های آینده نیستند.

برای انتشار یا توسعه، از `src/` و `worker/` استفاده کنید، نه `archive/KimiaBeauty/web/`.
