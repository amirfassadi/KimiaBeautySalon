# بازبینی و آماده‌سازی طراحی جدید کیمیا

تاریخ: 2026-11-11. مبنای ورودی Google AI Studio: commit `b73f44b`.

## نتیجه

نسخه اصلاح‌شده برای به‌روزرسانی کنترل‌شده VPS آماده است. ظاهر جدید شامل فونت IranNastaliq در تیترها، Estedad در متن‌ها، تصویر مفهومی با اولویت سالن زیبایی و گوشه‌های نرم حفظ شده است. این گزارش تأیید انتشار نسخه جدید روی VPS نیست.

## ایرادهای ورودی و اصلاحات

- نصب تمیز ورودی با `npm ci --ignore-scripts` شکست خورد: `pg` و وابستگی‌های آن و بسته‌های چندسکویی از lockfile حذف شده بودند. چون package.json تغییر وابستگی نداشت، lockfile آخرین نسخه بررسی‌شده بازیابی شد. `npm ci` سپس موفق بود و ۰ آسیب‌پذیری گزارش کرد.
- ورود/ثبت‌نام مشتری دوباره در هدر اضافه شده بود؛ ورودی‌های عمومی حذف شدند تا محدوده لانچ معرفی حفظ شود. مسیر ورود مدیر و کد قابلیت‌های آتی حفظ شدند.
- تصویر اصلی جدید با همان URL قدیمی و cache immutable ارائه می‌شد. build اکنون URL مبتنی بر hash محتوای تصویر می‌سازد و از kimia-salon-hero.webp استفاده می‌کند؛ مرورگرهای دارای کش تصویر قبلی نیز آدرس جدید می‌گیرند.
- متن پیش‌فرض Worker و پنل با متن طراحی جدید هماهنگ شدند. محتوای ذخیره‌شده مدیر در دیتابیس تغییر داده نمی‌شود.
- ارتفاع هدر و فاصله خطوط نام برند برای جلوگیری از بریدگی حروف نستعلیق اصلاح شدند؛ منوی موبایل با ارتفاع جدید هماهنگ است.
- تست Worker برای عدم حضور ورودی عضویت، تیتر پیش‌فرض جدید، تصویر نسخه‌دار و مسیر فونت جدید تقویت شد.

## نتایج تست واقعی

محیط: Windows x64، Node.js v24.20.0، npm 11.19.0، PostgreSQL 18.6 مجزای محلی با احراز هویت SCRAM و نقش غیر-superuser، Chrome headless.

## محدوده انتشار

- هیچ تغییر schema یا migration جدیدی برای طراحی لازم نیست؛ روی VPS migration اجرا نکنید.
- secretها، حساب مدیر، محتوای PostgreSQL، تصاویر آپلودشده و تنظیمات موجود Nginx/HTTPS باید حفظ شوند.
- قبل از جابه‌جایی release، از دیتابیس و تصاویر بکاپ بگیرید؛ release قبلی برای برگشت نگه داشته شود.
- پس از restart، health محلی و عمومی، صفحه اصلی، فونت/تصویر، ورود مدیر، sitemap و تماس‌ها روی دامنه واقعی بررسی شوند.
- اگر مدیر قبلاً عکس اصلی یا تیتر اختصاصی ذخیره کرده باشد، همان محتوا اولویت دارد؛ انتشار کد، محتوای او را بازنویسی نمی‌کند.
- تصویر تازه مفهومی است و عکس واقعی سالن یا نمونه‌کار مشتری محسوب نمی‌شود.
- بررسی مستقل PostgreSQL/Linux، systemd و Nginx نسخه جدید روی VPS هنوز انجام نشده است؛ مالک باید مراحل به‌روزرسانی و پذیرش نهایی را اجرا کند.

## نتیجه نگهداری HTTPS بر اساس خروجی مالک

Certbot مقصد 2.1.0 است؛ dry-run محدود به گواهی کیمیا موفق بود، hook نصب‌شده جداگانه nginx -t/reload موفق داشت و timerهای certbot.timer و snap.certbot.renew.timer دیده شدند. زمان‌بندی‌ها در این بازبینی تغییر نکردند؛ این شواهد، تأیید اجرای خودکار hook در تمدید آینده نیستند.
