# بهبود صفحات کوتاهی، رنگ مو و ناخن — ۲۱ نوامبر ۲۰۲۶

## مبنا

خروجی Search Console ارائه‌شده توسط مالک، با فیلتر Web و سه ماه اخیر، داده‌هایی از ۱۱ تا ۱۹ نوامبر دارد: ۵۸ نمایش، یک کلیک، CTR برابر ۱٫۷۲٪ و میانگین جایگاه ۱۶٫۶۹. عبارت «کوتاهی مو غرب تهران» یک نمایش و یک کلیک با جایگاه ۶ دارد؛ «بهترین سالن رنگ مو در غرب تهران» ۱۲ نمایش با میانگین ۵۴٫۹۲ دارد. حجم داده برای قضاوت درباره رتبه پایدار یا اثر تغییر کافی نیست. داده مشتری و ZIP اصلی به مخزن اضافه نشده‌اند.

## تغییرات

- URLهای موجود کوتاهی، رنگ و ناخن حفظ می‌شوند. توضیح پیش‌فرض این سه صفحه دقیق‌تر شده؛ محتوای اختصاصی و متادیتای ثبت‌شده مدیر همچنان اولویت دارند.
- راهنمای انتخاب مدل کوتاهی، مقایسه درخواست‌های رنگ و مقایسه کاشت/ترمیم/ژلیش به صورت HTML قابل خواندن بدون JavaScript اضافه شده‌اند.
- چک‌لیست اطلاعات لازم برای برآورد هزینه، مسیرهای داخل صفحه، لینک اینستاگرام سالن برای بررسی نمونه‌کار و تماس اختصاصی هر خدمت اضافه شده‌اند.
- لینک متنی کوتاهی و رنگ همراه توضیح مرتبط اضافه شده؛ غیرفعال‌سازی خدمت، این لینک‌ها را نیز حذف می‌کند. صفحه اصلی این سه راهنما را با توضیح قابل مشاهده معرفی می‌کند.
- جدول‌ها عنوان و سرستون دسترس‌پذیر دارند و برای موبایل شکستن متن و ستون‌بندی محدود دارند. تصویر مشتری، امتیاز، قیمت، تکنیک تضمین‌شده یا ادعای «بهترین سالن» ساخته نشده است.
- canonical، Service/BeautySalon/Breadcrumb، sitemap و اطلاعات تماس از مسیر مشترک قبلی استفاده می‌کنند؛ مهاجرت دیتابیس لازم نیست.

## پس از انتشار

اعتبارسنجی محلی: build، مجموعه کامل `npm test`، TypeScript و `git diff --check` موفق بودند. سه صفحه در Chrome با عرض‌های ۳۹۰ و ۱۴۴۰ بررسی شدند: پاسخ سالم، یک H1، جدول بدون سرریز افقی، متن جدول ۱۶ پیکسل و مقصد معتبر همه میانبرها. تست‌های PostgreSQL واقعی و rollback انتشار در workflow موجود CI اجرا می‌شوند؛ تست محلی دیتابیس از PGlite استفاده کرده است.

در URL Inspection سه URL زیر، تست نسخه زنده و سپس درخواست ایندکس انجام شود. دسترسی به حساب Search Console در این کار فراهم نیست؛ بارگذاری گزارش معادل دسترسی به حساب نیست.

- `https://kbkimiabeauty.ir/services/haircut`
- `https://kbkimiabeauty.ir/services/hair-color`
- `https://kbkimiabeauty.ir/services/nails`

در Performance، برای هر صفحه با کشور، دستگاه و نوع جست‌وجوی یکسان، بازه‌های کامل ۲۸ روزه مقایسه شود. عبارت‌های کوتاهی مو غرب تهران/صادقیه، رنگ مو غرب تهران/صادقیه و کاشت ناخن غرب تهران/صادقیه پیگیری شوند. رتبه لحظه‌ای و میانگین جایگاه معادل نیستند و افزایش رتبه تضمین نمی‌شود.

برای تکمیل مرحله بعد، عکس واقعی دارای مجوز هر خدمت و جزئیات تأییدشده سالن درباره تکنیک‌ها و قیمت لازم است. گالری عمومی مو به عنوان نمونه اختصاصی کوتاهی یا رنگ نمایش داده نمی‌شود.
